# Built With Grok — logo usage (short)

**Orbital Construct** mark: open geometric ring (aerospace orbit) + structural crossbar + precision terminal + intelligence spark. Monochrome-first. Not a SpaceX, Tesla, X, or SpaceXAI mark.

## Assets

| File | Use |
|------|-----|
| `logo-mark.svg` | Dark mark on light (print, light UI) |
| `logo-mark-light.svg` | Light mark on dark (web header, TV) |
| `logo-mark-mono.svg` | `currentColor` invert-safe web |
| `logo-lockup.svg` / `logo-lockup-light.svg` | Horizontal mark + “Built With Grok” |
| `logo-icon.svg` / `logo-icon-*.png` | Square app / Apple TV / Fire TV icons |
| `logo-icon-light.svg` / `logo-icon-light-*.png` | Light square variant |

Vector SVG is the source of truth. PNG sizes (128–1024) are convenience exports for stores and 10-foot UIs.

## Surfaces

- **Digital web:** Use `logo-mark-light.svg` (or mono) in the dark site header; lockup optional where space allows. Prefer SVG for retina.
- **Print:** Use `logo-mark.svg` (black) on white stock; convert lockup wordmark text to outlines in your layout tool for press. Minimum mark print size **12 mm** wide.
- **Apple TV / Fire TV / modern media:** Use square `logo-icon-1024.png` (or SVG icon) as the app/channel tile. Silhouette is bold for 10-foot recognition; do not use thin hairline-only versions.

## Clear space & minimum size

- Clear space: ≥ **¼ of the mark height** on all sides (no other logos or dense type inside that zone).
- Web minimum: mark **24 px** tall; lockup **20 px** text height.
- Do not stretch, recolor to gradients, add drop shadows, or place the mark on busy photography without a solid scrim.

## Do-nots

- Do not recreate or imply SpaceX / Tesla / X / SpaceXAI trademarks.
- Do not use the old CSS “BG” pill as the brand mark.
- Do not outline the mark in a second color or rotate off-axis for primary brand use.
