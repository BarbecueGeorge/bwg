## 1. Grok Product Sprint

### Value proposition

Turn a validated (or well-scoped) AI product idea into a **working digital MVP**—app, agent, workflow, or API-backed experience—using **Grok as the intelligence layer**, in a fixed window with clear acceptance criteria.

**For whom:** Founders, Heads of Product, CTOs who need something shippable to users, investors, or internal stakeholders—not another slide deck.

**Outcome:** Deployable demo or pilot-ready product, documented architecture, and a path to production (often via Production AI Systems or retainer).

### Scope (typical inclusions)

| In | Out (unless contracted) |
|----|-------------------------|
| Product framing workshop (light) | Full brand identity system |
| UX flows for core happy path | Multi-region HA / enterprise compliance program |
| Grok-powered core feature(s): chat, agent tools, voice, or structured generation as agreed | Extensive data labeling / custom model training |
| Frontend + backend for MVP scope | Deep ERP/legacy multi-system rewrite |
| Staging deploy + basic auth | 24/7 SLA ops |
| README, handoff notes, short Loom/walkthrough | Ongoing feature factory (use retainer) |

**Example deliverables**

- Customer-facing agent or copilot MVP  
- Internal ops tool with Grok reasoning + tools  
- Vertical workflow (e.g. content, support triage, research assistant)  
- Companion API + thin UI for a future physical product  

### Delivery notes

| Item | Detail |
|------|--------|
| **Duration** | 2–6 weeks (default 4) |
| **Team** | Product lead + 1–2 engineers; design as needed |
| **Cadence** | Kickoff → mid-sprint review → ship review |
| **Stack** | Grok/xAI APIs primary; modern web/app stack agreed at kickoff |
| **Entry** | Written brief or paid Discovery Workshop preferred |
| **Exit criteria** | Acceptance checklist signed; staging (or agreed host) live; source + docs handed over |
| **Pricing band** | £25k–£80k fixed-scope preferred; change orders for scope expansion |
| **Upsell path** | Production AI Systems · Monthly Retainer · Physical × AI Lab (if device path) |

### Risks & constraints

- Ambiguous success metrics → force metrics in kickoff  
- Client data access delays → time-box integrations; mock first  
- Model cost/latency surprises → budget usage caps and eval harness early

## 2. Production AI Systems

### Value proposition

Take a working AI demo or Sprint MVP and make it **production-grade**: reliable agents/tools/RAG, observability, cost control, security baselines, and launch support—so the product can serve real users under real load.

**For whom:** Teams past the “it works in a demo” stage; innovation pods ready for wider rollout; Sprint clients hardening for launch.

**Outcome:** Production (or production-candidate) system with runbooks, monitoring, cost visibility, and defined SLAs/ops ownership.

### Scope (typical inclusions)

| In | Out (unless contracted) |
|----|-------------------------|
| Architecture review & hardening plan | Full enterprise change-management program |
| Agent/tool/RAG quality improvements | Multi-year regulated platform build as day-one only scope |
| Auth, roles, audit basics appropriate to client | SOC2 audit certification (can advise/partner) |
| Observability: logs, traces, error budgets, usage | 24/7 NOC (partner or client ops) |
| Cost controls: caching, routing, rate limits, budgets | Custom foundation-model training |
| Evaluation harness for key prompts/tools | Unlimited feature backlog |
| Launch checklist & cutover support | Permanent staff-aug without product ownership |
| Integration hardening for critical systems | |

**Example deliverables**

- Hardened customer support agent with tool use + escalation  
- Knowledge RAG with evals, citation policy, and admin controls  
- Multi-step workflow agents with human-in-the-loop gates  
- Cost dashboard + alerting for Grok API spend  

### Delivery notes

| Item | Detail |
|------|--------|
| **Duration** | 4–16 weeks in phases (e.g. harden → launch → stabilize) |
| **Team** | AI/full-stack eng + product lead; optional SRE partner |
| **Cadence** | Weekly demos; written phase gates |
| **Stack** | Grok-first; existing client cloud preferred; observability stack agreed |
| **Entry** | Existing MVP/demo or completed Grok Product Sprint; access to envs and data samples |
| **Exit criteria** | Agreed production checklist met; runbooks delivered; ownership transfer or retainer started |
| **Pricing band** | £50k–£250k+ depending on integrations, compliance depth, and environments |
| **Upsell path** | Monthly Retainer · follow-on feature phases · Physical companion layer |

### Risks & constraints

- Production without data contracts → define PII and retention early  
- “Make it enterprise” scope creep → phase compliance; partner when needed  
- Single-model lock-in fears → document integration-ready boundaries

## 3. Physical × AI Lab

### Value proposition

Design and prototype **physical products with Grok-backed experiences**—connected devices, smart products, interactive installations, or companion hardware—without the client hiring a full hardware org. BWG owns product sense, AI UX, and software; **orchestrates** industrial design, electronics, firmware, and pilot manufacturing through partners.

**For whom:** Brands and startups wanting AI + atoms (companion devices, retail experiences, industrial operator tools with edge/cloud Grok); digital-first teams adding a physical SKU.

**Outcome:** Concept package, working prototype (fidelity agreed), companion app/agent experience on Grok, and a pilot manufacturing / next-steps plan.

### Scope (typical inclusions)

| In | Out (unless contracted) |
|----|-------------------------|
| Concept & experience design (physical + digital) | Mass production ownership without CM contract |
| Architecture: sensors/actuators, connectivity, cloud, Grok layer | Factory setup / tooling CAPEX (client or CM) |
| Companion app / voice / agent MVP on Grok | Full regulatory certification (FCC, CE, medical, etc.—partner path) |
| Firmware/app integration for prototype fidelity | Retail distribution and channel sales |
| Partner orchestration (ID, EE, CM shortlist) | Open-ended industrial R&D |
| BOM estimate & pilot plan | Guaranteed unit cost at scale without DFM cycles |
| Demo-ready prototype (count and fidelity in SOW) | |

**Example deliverables**

- Smart desk/object with Grok voice companion  
- Wearable or badge with contextual Grok assistant (privacy-aware)  
- Retail installation: physical kiosk + Grok conversational layer  
- Industrial handheld/operator aid with Grok reasoning + cloud tools  

### Delivery notes

| Item | Detail |
|------|--------|
| **Duration** | 6–20 weeks typical for concept → prototype (depends on fidelity) |
| **Team** | BWG product + software/AI lead; ID/EE/firmware partners; CM as needed |
| **Cadence** | Concept gate → breadboard/bench → integrated prototype → pilot plan |
| **BOM / tooling** | Prefer client-borne or pass-through; quoted separately from services fee |
| **Entry** | Clear use case, constraints (cost, size, power, safety), and success demo definition |
| **Exit criteria** | Agreed prototype acceptance; companion software demo; pilot manufacturing brief |
| **Pricing band** | Services £40k–£200k+; materials/tooling extra |
| **Upsell path** | Production AI Systems for cloud backend · Retainer for iteration · Sprint for v2 software |

### Risks & constraints

- Hardware timelines slip → stage software demos on mock hardware early  
- Supply and MOQ surprises → partner CM early; dual-source critical parts when possible  
- Safety/regulatory → do not promise certifications; plan specialist partners  
- Scope “full consumer electronics company” → keep Lab = prototype + path, not factory
